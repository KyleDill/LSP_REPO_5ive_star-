CRC Card Explanation — Library Lending System

Library collaborates with Book, but Book does not collaborate with Library, because the CRC responsibilities assign Book sole ownership of its own identity and availability state, while Library's responsibility is to coordinate a collection of Books it does not itself embody. Book has no need to know which Library (if any) holds it — it only needs to validate and change its own available flag — so adding a reference back to Library would create an unnecessary dependency in the direction of least knowledge (the "Don't talk to strangers" / minimal-coupling heuristic). Library enforces the three-book borrowing limit, rather than Book, because that limit is a property of the lending policy applied across an entire collection, not a property of any single book; a Book object has no way to know how many other books are currently borrowed from the same Library, so that responsibility can only be assigned to the class — Library — that actually holds the collection and can count across it.
